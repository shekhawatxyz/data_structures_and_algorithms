0) IF you're not sure what the problem is asking for, just clarify it with the LLM until you're clear about this.
1) Try to solve the problem on your own, even if you feel like your solution isn't the best or optimal, or you aren't entirely confident. Try to get it correct, try to get it provably correct, consider all the cases, etc.
1.2) Code it up.
1.3) If it works, go to code review.
1.4) If it doesn't work, then try to fix it. If you get stuck fixing it, *then* ask an LLM to direct your attention to think carefully about where is points you; this should usually fix the issue. If it does, move to code review.
1.5) If that doesn't, *then* ask the LLM for more help, maybe the minimum delta, but without giving the entire answer away. This should fix the problem; if it does, move to code review.
1.6) If and only if you've reached here after trying multiple loops of the above and are completely stumped, ask for direct help, if not the solution.
2) Core review and iterate.
This is for the first pass.
Second pass similarly, but any you get stuck on get added to deep practice.
(Second pass is when you go through, say, list challenges, one per day, and keep doing that until you're done; takes a month; this is the re-solving pass Bhaskar mentioned.)
