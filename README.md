# Data Structures and Algorithms

My working notebook for learning data structures and algorithms: implementations, practice problems, and daily logs.

## Layout

- `algorithms/` — standalone algorithm implementations (sorting, searching, etc.)
- `data_structures/` — data structure implementations
- `challenges/` — practice problems organized by topic (linked lists, stacks, queues, trees, tries, graphs, hashmaps), plus scripts to track/validate progress through them
- `2026-02/` — dated logs of daily practice sessions
- `running_list.md` — running checklist of topics covered and still to cover

See `AGENTS.md` for the workflow I use when solving problems with LLM assistance.
