# Challenge Order

Recommended solve order:

1. Linked Lists (`linked_list_challenges`)
2. Stacks (`stacks_challenges`)
3. Doubly Linked Lists (`doubly_linked_list_challenges`)
4. Queues (`queues_challenges`)
5. Binary Trees (`binary_trees_challenges`)
6. Red-Black Trees (`red_black_tree_challenges`)
7. Hashmaps (`hashmap_challenges`)
8. Tries (`trie_challenges`)
9. Graphs (`graph_challenges`)

This file records the intended learning order without renaming directories or
changing import paths.

## Progress Markers

Challenge markdown files use `_Problems: total._` problem counts and compact
problem rows:

```md
- [ ] **1a — Problem name** — Status:
```

Tick the problem row when it is done. Do not update a separate completed count
or a level heading checkbox. `Status:` is optional free text for notes like
`shaky`, `hard`, `revisit`, or `deep practice`.

Run `python challenges/validate_progress_markers.py` to check that every
challenge file has one problem marker and that the total problem count still
matches the files on disk.
